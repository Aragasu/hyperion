02

Hosting

Pulsar is offered only as a hosted bot: you add the running instance to a Yapper server and configure it through chat or the dashboard.

It is not self-hostable. We do not provide a source download, an install package, a public container image or setup instructions for running your own copy. The Node.js and Docker tooling used to operate the hosted instance is internal operations, not a distribution to users.

If you need a feature that the hosted bot does not provide, ask in Hyperion. Running a modified copy is not an available option.
