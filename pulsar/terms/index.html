What Pulsar is

Pulsar is a bot that provides moderation, tickets, automod, games, levels, custom commands, embeds and other tools to a Yapper server. It is free. There are no subscriptions, paid tiers, purchases or in-app payments, and we do not ask you for payment details.

Pulsar is offered only as a hosted bot. It is closed source and is not distributed for self-hosting; there is no source download, install package or public container image.

Pulsar is not a replacement for a human moderator, a backup, or a security service. It is a toolkit that acts on the settings a server gives it.

Your server is your responsibility

Server owners and administrators decide which features are enabled, what custom commands say, who may run moderation commands, and what happens in their server. Pulsar carries those decisions out. A kick, ban, timeout, message deletion, role change, channel creation, ticket closure or automated message is your server’s action, taken through Pulsar — not ours.

Make sure Pulsar has only the permissions it needs, and that the people you give access to can be trusted with them. If you are a moderator using a command, you are responsible for using it lawfully and within your server’s rules.

Worth knowing

Moderation tools act immediately and can be hard to undo. Test a new custom command or automod rule on a quiet channel before pointing it at a busy one.
